Primary action control — use for the single most important action in a view; imperative German verbs.

```jsx
<Button variant="primary" size="md" iconLeft={<i data-lucide="upload" />}>
  Datei hochladen
</Button>
```

Variants: `primary` (ignition red, glows on hover), `secondary` (hairline outline), `ghost` (text-only), `danger` (redline). Sizes: `sm` / `md` / `lg`. Props: `block`, `loading`, `disabled`, `iconLeft`, `iconRight`. Keep one primary per view.
