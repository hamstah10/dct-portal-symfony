Surface container for products, vehicles, and tuning files.

```jsx
<Card title="Stage 1 — 2.0 TDI" media="/assets/engine.jpg"
      badge={<Badge solid>Stage 1</Badge>}
      footer={<><span>ab 199 €</span><Button>In den Warenkorb</Button></>}
      featured interactive>
  <p>+38 PS · +72 Nm — auf dem Prüfstand abgestimmt.</p>
</Card>
```

`media` takes an image URL or a node. `featured` adds the ignition top rule; `interactive` adds hover lift.
