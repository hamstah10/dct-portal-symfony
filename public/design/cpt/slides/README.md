# Sample slides

Branded 1280×720 slide layouts in the Chiptuningfile system. Each is a self-contained HTML frame linking `../styles.css`.

- **`TitleSlide.html`** — dark hero opener: logo lockup, grid texture, oversized display headline, mono eyebrow.
- **`StatSlide.html`** — light figures showcase: three metric tiles, featured one with the ignition top rule.
- **`ComparisonSlide.html`** — Serie vs. Stage 1 columns (light vs. dark panels) with gain deltas.
- **`SectionSlide.html`** — dark section divider / big statement with progress marker.

Layout system: 72–96px margins, mono eyebrows, UPPERCASE Saira Condensed headlines, one accent per slide. To assemble a real deck, drop these `<section>`s into the `deck_stage.js` starter component.
